# 环孢素软胶囊的正确用法是什么

> 更新时间：2026-09-15 (UTC+8)

环孢素软胶囊是一种免疫抑制剂，在临床上常用于预防器官移植后的排斥反应以及治疗一些自身免疫性疾病。正确使用环孢素软胶囊对于确保其疗效和减少不良反应至关重要。以下是关于环孢素软胶囊的正确用法的详细解释：

1. 服用时间：环孢素软胶囊一般建议每日两次服用，两次服药的时间间隔为12小时，建议固定时间服用（如早晨9点和晚上9点）。这样可以保持药物在体内的稳定浓度，有助于提高疗效并减少副作用。

2. 与食物的关系：食物不会影响环孢素的吸收，因此餐前餐后用药都可以。但因环孢素个体差异大，建议保持相对稳定的饮食结构，以及每天固定的就餐时间和吃药时间。这有助于减少药物浓度的波动，从而降低不良反应的风险。

3. 服药方式：服用环孢素软胶囊时，应整粒吞服。当您打开包装时，可能会闻到一股特别的气味，这是正常现象。不要嚼碎或压碎软胶囊，以免影响药物的释放和吸收。

4. 剂量调整：环孢素软胶囊的剂量应根据患者的具体情况进行调整。一般来说，成人口服常用量开始剂量按体重每日12-15mg/kg，1～2周后逐渐减量，一般每周减少开始用药量的5%，维持量约为每日5～10mg/kg。对作移植术的患者，在移植前4～12小时给药。具体剂量应由医生根据患者的病情、年龄、体重等因素综合考虑后确定。

5. 漏服处理：如果漏服了环孢素软胶囊，尽可能在漏服后的4小时内补服。如果接近下一次服药的时间了，那跳过这次漏服，只吃下一次应该服用的剂量，千万不要吃双倍剂量的药。

6. 注意事项：

 - 定期监测：由于环孢素个体差异大，服用相同剂量的患者血中药物浓度可能相差很大。因此服用环孢素期间必须按照医生建议定期进行血药浓度的监测。

 - 避免相互作用：环孢素与许多药物存在相互作用，如红霉素、地尔硫卓、利福平、苯妥英钠、五酯胶囊等,这些药物都可能引起环孢素浓度的波动，导致毒副作用的发生，或影响药物疗效。因此需要联合使用其他药物时，需咨询医生或药师。

 - 注意副作用：环孢素使用过程中可能会出现牙龈增生、多毛症等副作用，一般停用药物后会慢慢消失。切不可因此擅自减量或停用环孢素。

 - 特殊人群慎用：儿童必须在成人监护下使用环孢素软胶囊。老年患者因易合并肾功能不全，故应慎用本品。

综上所述，环孢素软胶囊的正确用法包括每日两次固定时间服用、与食物关系不大但需保持稳定饮食结构、整粒吞服、根据医嘱调整剂量、注意漏服处理以及定期监测血药浓度等。同时，还需要注意药物的相互作用和副作用，并在特殊人群中慎用。
